⬡ How Scoring Works

We compare your hardware against each game's minimum and recommended requirements using a weighted scoring system:

Component Weight Why?
GPU 40 pts Graphics card matters most for gaming performance
RAM 25 pts Insufficient RAM causes stuttering and crashes
CPU 25 pts Processor handles game logic, AI, and physics
Storage 10 pts You need enough space to install the game

⬡ Frequently Asked Questions

Is this 100% accurate?
No tool can guarantee exact performance. CanItRun gives you a strong estimate based on official system requirements and our tier-based scoring model. Real-world performance depends on drivers, background processes, cooling, and more.
How do I know my GPU / CPU tier?
Check your device's specifications (Settings → System → About on Windows, or "About This Mac" on macOS). Match your graphics card and processor to the closest tier in our table above. When in doubt, pick the lower tier for a conservative estimate.
Can I check mobile games?
Yes! Switch the device type to "Mobile" on the home page. The OS dropdown will switch to Android/iOS versions, and the game grid will include mobile titles.
What tech stack is this built with?
Backend: Python + FastAPI. Frontend: Vanilla HTML, CSS, and JavaScript. Deployment: Docker + Google Cloud Run. No frameworks — just pure web fundamentals with a dark terminal aesthetic.
Can I contribute or add games?
This is an open project built for a GfG workshop. Feel free to fork the repo and add your own games to the data/games.py file!
